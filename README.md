# CodespacesHome

Dotfiles repo for GitHub Codespaces.

## Setup

1. Go to [GitHub Settings > Codespaces](https://github.com/settings/codespaces).
2. Under **Dotfiles**, check **Automatically install dotfiles** and select this repository.
3. New codespaces will clone this repo and run `install.sh` automatically.

## What it does

`install.sh` installs [Claude Code](https://claude.ai/install.sh) if it isn't already present.

Note: changes only apply to *new* codespaces, not ones already running.
